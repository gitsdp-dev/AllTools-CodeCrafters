# 🚀 What is AllTools?

AllTools is a modern browser-based file toolkit that helps users work with images, PDFs, and text files quickly and securely.

Unlike many online tools that upload your files to external servers, AllTools processes everything locally inside your browser, giving you complete control over your data.

Whether you need to compress images, merge PDFs, extract text, or perform quick file conversions, AllTools delivers a fast and privacy-friendly experience.

# 🚀 Local Development

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/all-tools.git
```

Navigate to the project:

```bash
cd all-tools
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```
